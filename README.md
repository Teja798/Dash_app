📚 Book Analysis Dashboard – Dash & Plotly

An interactive Power BI–style dashboard built using Dash + Plotly + Pandas to analyze book sales data.
Users can filter by Genre and all charts update dynamically in real-time.

🚀 Features

Dynamic Genre slicer

Auto-refreshing visuals like Power BI

Four interactive charts:

📊 Genre vs Stock

📊 Genre vs Price

📊 Genre vs Revenue

📈 Book_ID vs Published Year (bubble chart)

Real-time calculations using Python callbacks
